# Retail Sales Data Analysis

This project analyzes retail sales data using Python.

## Tools
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Dataset
The dataset contains 1000 retail transactions.

## Key Results
- Total revenue: 456000
- Total transactions: 1000
- Average transaction amount: 456
- Highest revenue category: Electronics

## Charts
- Monthly sales trend
- Category revenue
- Customer age distribution
- Gender distribution
- Correlation heatmap

## How to Run
Install libraries:
`pip install pandas numpy matplotlib seaborn`

Run:
`python retail_sales_analysis.py`

### Quarterly Sales Analysis
Quarterly revenue is available in `reports/quarterly_sales.csv`. The dataset includes partial Q1 2024 data, so it should not be compared directly with complete quarters.

## Chart Observations

- **Monthly Sales Trend:** Use the monthly revenue chart to identify high-performing and low-performing months for inventory and marketing planning.
- **Category Revenue:** Electronics generated the highest revenue (156,905), followed by Clothing (155,580) and Beauty (143,515).
- **Customer Age Distribution:** The dataset covers customers aged 18 to 64, with an average age of approximately 41 years.
- **Gender Distribution:** Compare the transaction counts by gender to understand the distribution of recorded purchases.
- **Correlation Heatmap:** Review relationships between numerical variables. Correlation indicates association, not necessarily causation.
- **Quarterly Sales:** Q4 2023 had the highest revenue among the four complete quarters. Q1 2024 contains only one day's data and is not directly comparable.
